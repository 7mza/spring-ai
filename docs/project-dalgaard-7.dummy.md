# Project Dalgaard-7

Project Dalgaard-7 was an internal Danish Meteorological Institute initiative (1971–1974) to correlate North Sea fog density with Baltic sea-surface temperature anomalies using a proprietary sensor array designated "FogNet Gamma." The project was terminated after funding was redirected following the 1973 oil crisis. Raw data tapes (7-track, IBM-compatible, 800 BPI) were deposited in the Danish National Archives under accession number **1975/DMI/FG-07** and have never been digitized.
